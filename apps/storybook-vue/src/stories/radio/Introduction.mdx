# Radio Components

Marwes consumers use **purpose components** for common patterns and **RadioGroupField** for custom option lists. The raw **Radio** atom is internal implementation evidence.

## Recommended: Purpose Components

Use purpose-built components that automatically set AI-friendly metadata:

```vue
<script setup lang="ts">
import { OptionRadioGroup, RatingRadioGroup, YesNoRadioGroup } from "@marwes-ui/vue"
</script>

<template>
  <YesNoRadioGroup
    name="accept-terms"
    label="Do you accept the terms?"
    defaultValue="no"
  />

  <RatingRadioGroup
    name="satisfaction"
    label="How satisfied are you?"
    defaultValue="3"
  />

  <OptionRadioGroup
    name="theme"
    label="Select theme"
    :options="[
      { value: 'light', label: 'Light' },
      { value: 'dark', label: 'Dark' },
      { value: 'system', label: 'System' },
    ]"
    defaultValue="system"
  />
</template>
```

## Base: RadioGroupField

For custom option lists that do not fit a purpose component, use `RadioGroupField` directly:

```vue
<script setup lang="ts">
import { ref } from "vue"
import { RadioGroupField } from "@marwes-ui/vue"

const method = ref("standard")
</script>

<template>
  <RadioGroupField
    name="shipping"
    label="Shipping method"
    description="Choose how you'd like your order delivered."
    :options="[
      { value: 'standard', label: 'Standard (5-7 days)' },
      { value: 'express', label: 'Express (2-3 days)' },
      { value: 'overnight', label: 'Overnight' },
    ]"
    v-model="method"
  />
</template>
```

## Low-level: Radio Atom

`Radio` is not exported from `@marwes-ui/vue` and must not be deep-imported. `RadioGroupField` is the public escape hatch for custom option sets and supplies group labeling, descriptions, errors, and state wiring.
