Theming

Wrap once, provide a theme, and brand every Marwes component.

One provider, one theme boundary

Marwes components consume resolved theme values from the framework provider and ship static preset CSS. There is no CSS-in-JS runtime in the component packages.

const theme = { color: { primary: "#5558ff" } }

<MarwesProvider theme={theme}>
  <App />
</MarwesProvider>
React consumers: use useTheme() when JavaScript needs resolved values. The styled theme contains CSS variable references whose definitions live below the document root.

Build one branded, accessible UI language across React, Vue, and Svelte.
