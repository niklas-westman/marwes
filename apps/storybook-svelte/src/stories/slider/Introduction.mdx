# Slider Component

Marwes consumers use **SliderField** for labeled form usage and purpose wrappers for common meanings. The raw **Slider** atom is internal implementation evidence.

## Component Architecture

```text
SliderField (Molecule)
Slider (Atom)
```

## Recommended: Purpose Components

Use purpose-built sliders when the control has a clear product meaning:

```svelte
<script>
  import { VolumeSlider, BrightnessSlider, RadiusSlider } from "@marwes-ui/svelte"
</script>

<VolumeSlider description="Adjust the current output level for media playback." />
<BrightnessSlider description="Tune the display intensity for the current workspace." />
<RadiusSlider description="Control the corner rounding used across the component set." />
```

## Base: SliderField (Molecule)

Use `SliderField` for forms and settings panels where the control needs a visible label,
supporting text, and edge values.

```svelte
<script>
  import { SliderField } from "@marwes-ui/svelte"
  let radius = $state(24)
</script>

  <SliderField
    label="Radius"
    description="Controls the corner rounding used by the UI."
    slider={{ min: 0, max: 48, step: 2, showTooltip: true }}
    bind:value={radius}
  />
```

## Low-level Usage

`Slider` is not exported from `@marwes-ui/svelte` and must not be deep-imported. Use `SliderField` and pass range behavior through its nested `slider` prop.

## Supported Atom Features

- `min`, `max`, and `step` define the numeric range
- `bind:value` for two-way binding
- `onvaluechange` callback for value updates
- `showTooltip` displays the current numeric value above the thumb
- `showTouchArea` enables the larger touch halo treatment from the PDF spec
- `disabled` preserves native disabled semantics
- Custom visual track with fill, thumb, and touch-area elements

## Accessibility Notes

- Renders a native `<input type="range">` for keyboard support
- Always provide the `SliderField` label
- Use helper text, errors, and `ariaValueText` when the value needs more context
- Use `ariaValueText` when the raw numeric value needs a more descriptive spoken label

## Component Reference

**`VolumeSlider`** — Audio and media output levels (`data-purpose="volume"`)

**`BrightnessSlider`** — Visual intensity adjustments (`data-purpose="brightness"`)

**`RadiusSlider`** — Corner rounding controls (`data-purpose="radius"`)

**`SliderField`** — Field wrapper with label, helper/error, and min/max values

**`Slider`** — Internal range atom shown for implementation evidence; not a consumer import.
