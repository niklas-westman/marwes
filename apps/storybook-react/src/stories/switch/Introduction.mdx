# Switch Components

Marwes consumers use **purpose components** for common toggle use cases and **SwitchField** for standard field composition. The raw **Switch** atom is internal implementation evidence and is not a public package export.

## Recommended: Purpose Components

Use purpose-built components when the toggle has a clear product meaning:

```tsx
import { FeatureToggle, PermissionSwitch, PreferenceSwitch } from "@marwes-ui/react"

const [featureEnabled, setFeatureEnabled] = React.useState(true)

<FeatureToggle
  label="Enable beta dashboard"
  description="Turn on early access to the redesigned analytics experience."
  switch={{ checked: featureEnabled, onCheckedChange: setFeatureEnabled }}
/>

<PreferenceSwitch
  label="Use compact layout"
  description="Show denser spacing in lists and tables."
  switch={{ checked: false }}
/>

<PermissionSwitch
  label="Can manage billing"
  description="Grant access to invoices and subscription changes."
  switch={{ checked: true }}
/>
```

## Base: SwitchField (Molecule)

For a single labeled switch with optional description and error text, use `SwitchField`:

```tsx
import { SwitchField } from "@marwes-ui/react"

const [enabled, setEnabled] = React.useState(false)

<SwitchField
  label="Enable notifications"
  description="Receive important account and product updates."
  switch={{ checked: enabled, onCheckedChange: setEnabled }}
/>

<SwitchField
  label="Require review before publishing"
  error="Review mode must stay enabled for this workspace."
  switch={{ checked: false }}
/>
```

### SwitchField Features

- **Accessible field wiring** - uses `aria-labelledby` for the visible label and merges description/error ids into `aria-describedby`
- **Label + description + error** - standard field semantics without repeating layout boilerplate
- **Controlled toggling** - forward `checked` and `onCheckedChange` through the nested `switch` prop
- **Purpose-ready wrapper** - accepts `dataAttributes` so context variants can layer in metadata

## Low-level: Switch (Atom)

`Switch` is not exported from `@marwes-ui/react` and must not be deep-imported. Use `SwitchField` and pass size or state through its nested `switch` prop.

## Size API

The public `SwitchField` supports three Figma-matched sizes through `switch.size`. `compact` remains the default.

- `compact` - 24×16 track with 12px thumb
- `wide` - 30×16 track with 12px thumb
- `rich` - 30×20 track with 16px thumb

```tsx
import { SwitchField, SwitchSize } from "@marwes-ui/react"

<SwitchField label="Compact" switch={{ size: SwitchSize.compact }} />
<SwitchField label="Wide" switch={{ size: SwitchSize.wide }} />
<SwitchField label="Rich" switch={{ size: SwitchSize.rich }} />
```
